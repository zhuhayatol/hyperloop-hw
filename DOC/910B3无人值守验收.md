## 项目实际执行的交接

- 入口采集并冻结原版输出。Evaluator 将原版计时交给 Coordinator。Profiler 采了 Prefill、Decode 的 rank 0 trace，Trace Analyzer 返回矩阵乘、Attention 等热点。SGLang 在线停止接口返回 500，两段均从同一次 CANN 采集中离线导出并校验。
- Orchestration 将 768、1024 交给 Intent Router，Dispatcher 派给 Explorer。两项回退后，Coordinator 写下换向记录，Orchestration 将热点交给 Specialist。Specialist 提议 384、256，Critic 附意见批准，这两项实测后也回退。
- 第二轮 Specialist 又提出 640／576 和 640／896。Critic 根据上一轮结果分别拒绝和要求复审，两份未派发测速。三种角色均有实际 DeepSeek 回复，共 10 次 HTTP 200，22,581 token，其中输出 1,583 token。源码框架补丁没有进入集成环节。
- Kernel Agent 两次向 Forge 交付热点。Forge 分别构建并验证了 SwiGLU，Evaluator 隔离启动加载它的 SGLang 版本，独立核对输出并做端到端配对测速。两次均回退。实际覆盖文件为 `python/sglang/srt/layers/activation.py`，补丁及加载回执均已保存。这轮选用 Forge，GEAK 未执行。
