SGLang 真机校验与计时

样本来自 NPU 服务
  1. Evaluator明确版本、启动参数和待测请求SGLang 适配器
  2. SGLang 适配器固定输入 token 与生成长度SGLang /generate
  3. SGLang /generate输出 token IDs 与实际请求长度Verifier 正确性检查
  4. Verifier确认版本与 Reference 匹配，才开始计时BenchmarkRunner
  5. SGLang /generate服务返回流式响应，客户端记录首 token 与完成时间BenchmarkRunner
  6. Verifier 与 BenchmarkRunner输出核验、重复样本和环境身份Session 证据
三项指标从哪里来

吞吐用整个测量窗口内的生成 token 数计算。TTFT 是请求到首个输出 token 的时间，TPOT 是首个 token 后平均每个 token 的时间。

独立裁决与会话报告

  1. Session 证据读原始版、父版、候选与锁定门槛独立裁决
  2. 独立裁决KEEP、REVERT 或 HOLD，附理由Coordinator 写回
  3. Coordinator 写回存版本决定、事件与报告链接Session 报告

正确性

固定请求的输出须匹配独立 Reference。失败即退回候选并跳过性能计时。

性能与证据

同条件复测，收益达标且守住延迟门槛才保留。回归或收益不足予以退回。证据不足时暂缓裁决。
