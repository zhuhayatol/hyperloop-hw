# Hyperloop

Hyperloop 面向昇腾 SGLang 独立实现 Hyperloom 的优化编排。Coordinator 驱动角色回合、候选准入、任务派发和结果写回。设备执行端负责启动、采集、测量和清理，独立评测层关联每次候选的原始样本和裁决。

本地演练使用确定性回复与模拟设备，输出标记为 `simulated`。910B3 真机初验通过独立运行端访问实际 SGLang 服务，输出标记为 `real`。这轮的调参意图仍采用固定输入。[910B3 部署与初验](DOC/910B3部署与初验.md) · [初验信号流](DOC/910B3初验信号流.html)
